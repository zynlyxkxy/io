# 控制层开发需求 v2

## 1. 整体架构

```
RPC(ZMQ) → IoServer(胶水层) → IoController(控制层) → AcsIoModule/PlcIoModule → 硬件
                ↑                      ↑
          继承平台生成的          读config,注册observer,
          UIRpcControllerServerImpl  路由varId,校验verify
```

**IoServer**（胶水层）: 纯转发，继承 `UIRpcControllerServerImpl`（平台生成）。每个 RPC 方法转发给 `IoController`，并打印 `[RPC]` 日志（`std::cout`），方便排查问题。

**IoController**: 核心逻辑，负责：
- 读 config JSON，建内存索引
- 初始化 AcsIoModule / PlcIoModule
- AO/DO 的 observer 绑定关系管理
- 注册全部 observer 到轮询（AI/DI/AO/DO 各自独立）
- varId 路由（`segment % 2` 判 ACS/PLC）
- SetAo/SetDo 的 verify 异步校验
- Observer 周期推送（AI/DI/AO/DO/Buf 五路归类）、心跳、SetCompleted 推送

## 2. 号段路由

`segment = varId / 1000`，偶数 = PLC，奇数 = ACS：

| seg | 范围 | 硬件 | 类型 |
|-----|------|------|------|
| 0 | 0..999 | PLC | AI |
| 1 | 1000..1999 | ACS | AI |
| 2 | 2000..2999 | PLC | DI |
| 3 | 3000..3999 | ACS | DI |
| 4 | 4000..4999 | PLC | AO |
| 5 | 5000..5999 | ACS | AO |
| 6 | 6000..6999 | PLC | DO |
| 7 | 7000..7999 | ACS | DO |
| 8 | 8000..8499 | PLC | SettingDouble |
| 8 | 8500..8999 | PLC | SettingBool |
| 9 | 9000..9999 | ACS | Buffer |
| 10 | 10000..10999 | PLC | Cmd |

```cpp
inline int segment(int varId) { return varId / 1000; }
inline bool isPlc(int varId)  { return segment(varId) % 2 == 0; }
inline bool isAcs(int varId)  { return segment(varId) % 2 == 1; }
```

## 3. ConfigManager — 单例

### 3.1 设计原则

- 单例，全局唯一
- QSerializer 加载 JSON
- 直接暴露所有 map / 配置字段
- AO/DO 的 observer 是独立字段，不混在 AI/DI 的 map 里

### 3.2 数据加载流程

```
ConfigManager::instance().load("config/config.json")
  │
  ├─1. 读 config.json → m_acs.*, m_plc.*, m_verifyTimeoutMs
  │
  ├─2. 读 acs/io_config.json
  │     ai[] → acsAiMap, di[] → acsDiMap, ao[] → acsAoMap
  │     do[] → acsDoMap, Buffer[] → acsBufMap
  │
  └─3. 读 plc/io_config.json
        遍历 machineParts[]
          ai[] → plcAiMap[id] = {fullPath, name}
          di[] → plcDiMap[id] = {fullPath, name}
          ao[] → plcAoMap[id] = {fullPath, name, observer}
          do[] → plcDoMap[id] = {fullPath, name, observer}
          Cmd[] → plcCmdMap[id] = {fullPath, name}
          SettingDouble[] → plcSettingDoubleMap[id] = {fullPath, name}
          SettingBool[]   → plcSettingBoolMap[id] = {fullPath, name}
```

## 4. IoController 初始化流程

```
IoController::init()
  │
  ├─1. ConfigManager::instance().load("config/config.json")
  │
  ├─2. AcsIoModule(ip, port) + setPollPeriod
  │
  ├─3. PlcIoModule(ip, port) + setPollPeriod + addPath 所有 machinePart
  │
  ├─4. 注册全部 observer 到轮询:
  │     ACS: registerAi / registerDi / registerBuffer
  │     PLC: registerObserver(fullPath, name)
  │
  ├─5. connect observer 推送信号 → onAcsObsRefreshed / onPlcObsRefreshed
  │
  ├─6. 心跳 timer (1s)
  │
  └─7. verify timer (100ms)
```

## 5. LOCAL_DEBUG 模式

`CMakeLists.txt` 第 3 行：`add_compile_definitions(IO_LOCAL_DEBUG)` — 整个项目的本地调试开关。

### 5.1 ACS 模拟（AcsClient 层）

- `Connect()` / `Disconnect()` / `IsConnected()`: 仅操作标志位
- `ReadInteger()`: `qHash(varName) % 2 == 0 ? 1 : 0` — 稳定不变
- `ReadReal()`: `rand() / RAND_MAX * 10.0 - 5.0` — 每次随机
- `WriteInteger()` / `WriteReal()`: 直接返回 true
- 轴操作: 全部返回 true，Get 类返回 0
- `GetMotorState()`: 返回 `ACSC_MST_ENABLE | ACSC_MST_INPOS`
- `IsBufferRunning()`: `nBuffer % 2 == 0`

### 5.2 PLC 模拟（PlcIoModule 层）

在 PlcIoModule 层处理（不是在 PlcClient），因为需要区分 AI/DI：

- `getAi()`: `rand() / RAND_MAX * 10.0 - 5.0` — 模拟随机模拟量
- `getDi()`: `qHash(key) % 2 == 0` — 稳定 bool 值
- `onPollTimer()`: 按 `aiNames`/`diNames` 分别生成随机浮点或 hash bool
- `setAo()` / `setDo()` / `executeCmd()` / `setSettingDouble()` / `setSettingBool()`: 直接返回 Success
- PlcClient 层保留 `getMachinePartProperties` mock（空模板），但 observer 值不再走 PlcClient

### 5.3 关闭本地调试

注释 CMakeLists.txt 第 3 行即可连接真实硬件。

## 6. Observer 周期推送

### 6.1 ACS

```
onAcsObsRefreshed():
  data.AI  ← 遍历 acsAiMap，getAi → ObserverDoubleEntry{id, value}
  data.DI  ← 遍历 acsDiMap，getDi → ObserverBoolEntry{id, value}
  data.AO  ← 遍历 acsAoMap，getAi(observer) → ObserverDoubleEntry{id, value}
  data.DO  ← 遍历 acsDoMap，getDi(observer) → ObserverBoolEntry{id, value}
  data.Buf ← 遍历 acsBufMap，getBufferRunning → ObserverBoolEntry{id, value}
  emit sig_AcsObserverDataReady(data)
```

### 6.2 PLC

```
onPlcObsRefreshed():
  data.AI ← 遍历 plcAiMap，getAi(fullPath, name) → ObserverDoubleEntry{id, value}
  data.DI ← 遍历 plcDiMap，getDi(fullPath, name) → ObserverBoolEntry{id, value}
  data.AO ← 遍历 plcAoMap，getAi(fullPath, observer) → ObserverDoubleEntry{id, value}
  data.DO ← 遍历 plcDoMap，getDi(fullPath, observer) → ObserverBoolEntry{id, value}
  emit sig_PlcObserverDataReady(data)
```

## 7. SetAo/SetDo 异步校验 (Verify)

- **浮点容差**: `VERIFY_EPSILON = 1e-12`
- **per-varId 互斥**: pending 期间同一 varId 再次 Set 返回 `IO_ERR_BUSY` (-4)
- **校验超时**: `verifyTimeoutMs` 后 emit `sig_SetCompleted(varId, false, 1)`
- **verify=false**: 下发即结束，不入队

## 8. IoServer RPC 日志

所有 RPC 方法入口均有 `std::cout << "[RPC] ..."` 日志，格式如下：

| 方法 | 日志内容 |
|------|---------|
| GetServerInfo | `[RPC] GetServerInfo OK` |
| GetAi / GetDi / GetAo / GetDo | `[RPC] GetAi varId=... forceRefresh=... val=... err=...` |
| GetBufferRunning | `[RPC] GetBufferRunning varId=... forceRefresh=... val=... err=...` |
| SetAo / SetDo | `[RPC] SetAo varId=... val=... verify=... expect=... ret=...` |
| StartBuffer / StopBuffer | `[RPC] StartBuffer varId=...` |
| ExecCmd | `[RPC] ExecCmd varId=...` |
| SetSettingDouble / SetSettingBool | `[RPC] SetSettingDouble varId=... val=... ret=...` |
| CustomCommand | `[RPC] CustomCommand jsonCount=...` |

## 9. 错误码约定

| errorCode | 含义 |
|--------|------|
| 0 | 成功 |
| -1 | varId 未在 config 中找到 |
| -2 | 读取失败（硬件通信错误） |
| -3 | 写入失败（硬件通信错误） |
| -4 | 忙（同一 varId 的 verify 还在 pending） |

`SetCompletedData.errorCode`:

| errorCode | 含义 |
|--------|------|
| 0 | 校验通过 |
| 1 | 校验超时 |
| 2 | 下发失败 |

## 10. v1 → v2 核心变更

| 项 | v1 | v2 |
|----|----|----|
| 号段 | ACS 先 | PLC 先（偶数段），`seg%2` 判硬件 |
| AO observer | verifyObservers 数组 | **单个 observer，AO=double, DO=bool** |
| 期望值 | 写死在 config JSON | **RPC 调用方传入 expectedValue** |
| Observer 推送 | AI/DI 两路 | **AI/DI/AO/DO/Buf 五路归类** |
| Setting | 统一 RpcSetSetting | **RpcSetSettingDouble + RpcSetSettingBool** |
| GetServerInfo | 无 | **新增** |
| LOCAL_DEBUG | 无 | **ACS + PLC 全链路模拟** |
| RPC 日志 | 无 | **所有 RPC 入口有 std::cout 日志** |
